# Fan Content Permissions

This project ("Which Uma Are You?") is a non-commercial, fan-made
personality quiz that uses character names, characteristics, and
personality concepts associated with Umamusume: Pretty Derby. This
document records the permission/guideline terms provided by the project
owner and governs how character content and assets may be used in this
codebase. Keep this file up to date if terms are clarified or expanded,
and check it before adding new character content, assets, or any
monetization-adjacent feature.

## Source

Provided by the project owner via chat, 2026-08-21. Reproduced below
verbatim, followed by how this project applies it.

> RIGHTS:
> UMA ACCESS TO:
> CHARACTERISTICS
> PERSONALITY
> CHIBI SPRITES
> NORMAL SPRITES
> IMAGES FROM UMAS
>
> CANTS:
> YOU CANT:
> USE UMAS FOR MONETIZATION
>
> ALLOWED:
> 2ND PARTY DONATIONS, NO SELLING/BUYING UMA COSMETICS

## Rights — what this project may use

- Character characteristics
- Character personality
- Chibi sprites
- Normal sprites
- Images of/from the characters

## Restrictions — what this project must not do

- Must NOT use the characters for monetization, in any form. This
  includes (non-exhaustively) paid character unlocks, paid cosmetics or
  skins tied to characters, ads gated behind character content, or
  selling/buying anything described as an "Uma cosmetic."

## Explicitly allowed

- Second-party donations (i.e. through a third-party platform such as
  Ko-fi or Patreon, supporting the project itself) are allowed.
- Selling or buying character ("Uma") cosmetics is explicitly **not**
  allowed, even under the donations allowance above — the donations
  permission does not extend to any character-tied storefront.

## How this project applies these terms

- **No factual character dossier was provided alongside this rights
  grant.** This document governs *permission scope*, not character facts.
  Character summaries, strengths, weaknesses, and race-strategy flavor
  text in `js/characters.js` are original fan interpretations consistent
  with each character's well-known public archetype — the same approach
  used since the project's first version — not claims of official,
  sourced characteristic data. If official reference material becomes
  available, character content should be revised to match it and this
  note updated.
- **No character images are bundled in this repository.** `image` paths
  in `characters.js` point to where permitted assets will live
  (`assets/characters/<id>.webp`) once provided separately by the project
  owner. This codebase does not fabricate, source, hotlink, or hold any
  character artwork itself — see `assets/characters/README.md`.
- **No monetization involving characters exists or is planned.** No paid
  unlocks, no paid cosmetics, no character-gated purchases.
- **A voluntary, second-party donation section is permitted by these
  terms** (supporting the project itself, not selling anything
  character-related) but has not been implemented — it's out of scope
  until explicitly requested.
